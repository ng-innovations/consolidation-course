Layer 3 — Overview

Advanced Concepts

Coming soon

Layer 3 is a planned section of the course. No lessons are published yet. This page describes the intent.

Layer 3 covers the edge cases and complexities that don't belong in a first pass through Layer 2. The Layer 2 lessons are written for functional understanding — enough that a reader can follow what the consolidation engine does on a typical case. Layer 3 picks up the wrinkles: the variations, the rare scenarios, the "but what about…" questions that would have distracted from the core narrative.

What goes here

Topics that are likely to land in Layer 3 include:

  • Step acquisitions and partial disposals (when ownership percentages change mid-period)
  • Full goodwill vs. partial goodwill methods, and when each is required
  • Multi-tier ownership chains and bottom-up consolidation order
  • Reverse acquisitions and other unusual control structures
  • Hyperinflationary economy translation (a different FX treatment under both GAAP and IFRS)
  • Push-down accounting
  • Common-control transactions (acquisitions within an existing parent's group)
  • Equity method investee impairment
  • Deferred tax implications of consolidation adjustments

The list will grow as Layer 2 lessons get refined and edge cases get pulled out. Each Layer 2 lesson should be able to cross-reference Layer 3 with a phrase like "see Advanced Concepts 3.5 for more on step acquisitions" rather than getting tangled in the wrinkle itself.

Who this layer is for

Layer 3 is for readers who have finished Layer 2 and need to handle a specific complex scenario, either because they're building a feature that handles it or because they're trying to understand existing code that does. It's not required reading; it's reference.

How Layer 3 differs from Layer 4

Layer 3 covers complexities that can appear in any group. Layer 4 (Industry-Specific Handling) covers complexities that are specific to particular industries — REITs, PE fund-of-funds, banks, insurance. If an edge case applies broadly, it belongs in Layer 3. If it's only meaningful in one industry, it belongs in Layer 4.
