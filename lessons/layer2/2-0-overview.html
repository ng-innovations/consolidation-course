Layer 2 — Overview

Consolidation Steps

Layer summary

Layer 2 covers the granular operations of consolidation — one lesson per step in the workflow from Lesson 1.5. Each lesson explains a specific operation, walks through a worked example with small round numbers, and (in time) embeds a live spreadsheet grid you can edit to watch the same operation run on real data. Fifteen lessons, taught in pedagogical order — the consolidation steps first, then the four primary financial reports they feed into, then the broader reporting and disclosures package.

What you should take away

By the end of Layer 2 you should be able to read the consolidation engine's code and understand what each piece is doing and why — how COA mapping works, how currency translation produces CTA, how intercompany activity is eliminated, how goodwill and non-controlling interest fall out of acquisition accounting, and how the consolidated financial statements get assembled at the end. Edge cases that would distract from the first pass are punted to Layer 3.
